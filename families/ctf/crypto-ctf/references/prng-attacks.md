# PRNG Attacks

Attacks on pseudo-random number generators in CTF challenges.

## Mersenne Twister (MT19937) State Recovery

**When**: 624 consecutive 32-bit outputs from Python's `random`
module (or any MT19937 implementation) are available.

**How**: MT19937 has a 624×32-bit internal state. Each output is a
deterministic "tempered" transformation of one state word. Invert
the tempering to recover the state, then predict all future outputs.

```python
def untemper(y):
    # Invert the MT19937 tempering transform
    y ^= y >> 18
    y ^= (y << 15) & 0xEFC60000
    # Invert y ^= (y << 7) & 0x9D2C5680 (iterative)
    for i in range(7):
        y ^= (y << 7) & 0x9D2C5680
    # Invert y ^= y >> 11 (iterative)
    y ^= y >> 11
    y ^= y >> 22
    return y

# Collect 624 outputs, untemper each, set as MT state
import random
mt_state = [untemper(output) for output in outputs_624]
# Reconstruct the state tuple
state = (3, tuple(mt_state + [624]), None)
random.setstate(state)
# Now random.getrandbits(), random.randint(), etc. predict future values
```

### From Float Outputs

**When**: Outputs are `random.random()` floats (53-bit precision),
not raw 32-bit integers.

**How**: Each float uses the top 27 bits of one output and top 26
bits of the next. Recover partial state bits, then use lattice
methods (GF(2) matrix) to recover full state.

```python
# Each float = (a * 2^27 + b) / 2^53
# a = top 27 bits of output i (genrand_int32 >> 5)
# b = top 26 bits of output i+1 (genrand_int32 >> 6)
# 312 floats → 624 partial words → solve for full state
```

## Linear Congruential Generator (LCG)

**When**: Outputs follow x_{n+1} = a*x_n + b mod m.

**How**: Three consecutive outputs x0, x1, x2 determine a, b, m.

```python
# Recover modulus m from differences
# t_n = x_{n+1} - x_n
# m divides t_n * t_{n+2} - t_{n+1}^2 for all n
from math import gcd
from functools import reduce

def recover_lcg(outputs):
    diffs = [outputs[i+1] - outputs[i] for i in range(len(outputs)-1)]
    zeroes = [diffs[i+2] * diffs[i] - diffs[i+1]**2 for i in range(len(diffs)-2)]
    m = reduce(gcd, zeroes)
    m = abs(m)
    a = (outputs[2] - outputs[1]) * pow(outputs[1] - outputs[0], -1, m) % m
    b = (outputs[1] - a * outputs[0]) % m
    return a, b, m
```

**Truncated LCG**: If only partial bits are output (e.g., top 32
bits of a 64-bit state), use lattice methods to recover full state.

## C srand/rand Seed Brute-Force

**When**: A C program uses `srand(time(NULL))` and `rand()`.

**How**: `time(NULL)` returns Unix timestamp — brute-force a window
around the known time.

```python
import ctypes
import time

libc = ctypes.CDLL("libc.so.6")
target_output = ...  # first rand() output observed
now = int(time.time())

for seed in range(now - 3600, now + 1):
    libc.srand(seed)
    if libc.rand() == target_output:
        print(f"Seed found: {seed}")
        # Predict future outputs
        for _ in range(10):
            print(libc.rand())
        break
```

**Gotchas**: Different libc implementations (glibc, musl, macOS)
have different `rand()` algorithms. Match the target platform.

## LFSR (Linear Feedback Shift Register)

**When**: Output is generated by a linear recurrence over GF(2).

**How**: Given 2*degree output bits, use the Berlekamp-Massey
algorithm to recover the minimal polynomial (feedback taps).

```python
# SageMath
from sage.matrix.berlekamp_massey import berlekamp_massey
R.<x> = GF(2)[]
bits = [...]  # output bits as 0/1
poly = berlekamp_massey(bits)
# poly gives the feedback polynomial
# Once known, predict all future bits
```

**Correlation attack**: If the LFSR output is combined with other
LFSRs (e.g., XOR, majority), use correlation between each LFSR's
output and the combined output to recover individual LFSR states.

## ChaCha20 / Salsa20 State Recovery

**When**: Known-plaintext with a stream cipher based on ChaCha20.

**How**: ChaCha20's keystream is deterministic given (key, nonce, counter).
With known plaintext, recover keystream bytes → if key reuse or nonce
reuse is present, recover key material.

## Custom PRNG

For custom PRNGs:
1. Identify the state update function (linear? polynomial? lookup?).
2. If linear over GF(2) or GF(p): matrix/polynomial methods.
3. If nonlinear: try Z3 constraint solving or SAT.
4. If state is small: brute-force the seed space.
